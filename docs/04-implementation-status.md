## Что сделано в этой итерации

- Перенесена структура документации из `ai-ticketbuyer`: нумерованные документы, ADR, прототип, README с индексом.
- Базовый промпт исправлен: убран пример с выдуманным опытом и числами, правила фактов стали обязательными, стиль вынесен в конфигурацию.
- Бренд-ассеты закреплены из `iilmchat/ai-brand` по коммиту `e143a2b`.
- Заведён приватный репозиторий `iilmchat/ai-dzenwriter`.

## Что не сделано

- Код приложения, CI, Docker, миграции.
- Адаптер LLM и выбор провайдера.
- Интеграция с GitHub OAuth.
- Юридическая проверка: реклама, персональные данные, маркировка ИИ-контента.
- Проверка официальных возможностей публикации и импорта Дзена. Нужна справка Дзена; см. [ADR-0002](adr/0002-dzen-publishing-manual.md).
- Оценка стоимости генерации на реальных данных.

## Что проверено

- Бренд-ассеты совпадают с `ai-brand` по коммиту `e143a2bb894ec532f0afcdf9c5e4d48d83612405`.
- Конфиги `config/` разбираются YAML-парсером (PyYAML). Проверка схемы (`allowed_formats`, ключи `checks`) появится вместе с валидатором в E5.
