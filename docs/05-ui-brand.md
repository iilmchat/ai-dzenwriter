# UI и брендинг

**Статус:** черновик v0.1  
**Дата:** 22.10.2026  
**Источник брендинга:** [iilmchat/ai-brand](https://github.com/iilmchat/ai-brand), версия 1.1, коммит закреплён в [`design/brand/README.md`](../design/brand/README.md)  
**Связанные документы:** [00-design](00-design.md), [03-mvp-backlog](03-mvp-backlog.md)

---

## 1. Принципы интерфейса

1. **Редакторская работа, а не витрина.** Каждый экран помогает решить, что делать дальше и что блокирует.
2. **Статус всегда виден.** У каждого материала видны статус, владелец, блокирующие проверки и следующий шаг.
3. **Проверки рядом с текстом.** Панель проверок не прячется; клик по проверке переводит к месту в тексте.
4. **Спокойная палитра.** Фиолетовый — действие и выбор; красный — только блокировка; основной цвет текста — нейтральный.
5. **Русская локаль по умолчанию.** Даты, числа и склонения следуют `ru-RU`.

## 3. Сетка и адаптивность

- Шапка — 56 px. Боковое меню — 232 px развёрнуто и 72 px свёрнуто. Контент — до 1440 px.
- Доска — шесть колонок при ширине от 1440 px, минимум 180 px на колонку. Меньше — горизонтальная прокрутка колонок.
- Редактор — три зоны: исходник, предпросмотр, панель проверок шириной 300–320 px. Ниже 1100 px панель проверок уходит под предпросмотр.
- Ниже 768 px доступен только просмотр материалов. Редактирование — на десктопе, как и в v1.
- Отступы кратны 4 px. Радиусы: карточки 12 px, поля ввода 8 px, чипы и кнопки — полностью скруглённые.

## 5. Доска (`/board`)

Колонки: **Идея · Факты · Черновик · Ревью · Утверждено · Опубликовано**. Архив — за фильтром.

Карточка содержит:

- заголовок (рабочий или тема);
- чип стиля и чип формата;
- строку статуса текстом: «нужно 2 факта (1 из 2)», «2 блокирующих», «готово к ревью», «запланировано на 28.10»;
- инициалы владельца и дату обновления.

Фильтры: стиль, владелец, «только с блокировками», плановая дата.

Перетаскивание работает с клавиатуры. Переход статуса проходит через API и гейты. Недопустимый переход показывает причину, карточка возвращается на место.

## 6. Редактор (`/articles/:id/edit`)

Схема экрана:

```text
[Шапка]  Название материала  ·  [стиль]  [формат]  [статус]  ·  версия 3  ·  7 340 знаков

[Исходник Markdown]              [Предпросмотр, 680 px]              [Панель проверок]
  # Заголовок                      Заголовок                           Блокирует (1)
  Вступление…                      Вступление…                         — «38 %»: нет факта
  ## Блок 1                        ## Блок 1                           Предупреждения (1)
                                                                       — «самый быстрый»
                                                                       Информация (1)

[Метаданные]  SEO-заголовок 58/70  ·  Теги 6/7  ·  Описание  ·  IMAGE_PROMPT [копировать]
[Сгенерировать заново]  [Сохранить версию]        Заблокировано: 1 проверка   [На ревью]
```

Правила:

- Непроверенные числа и утверждения в предпросмотре подчёркиваются. Подсказка при наведении объясняет проблему.
- Клик по проверке переводит курсор в исходник и подсвечивает фрагмент.
- Кнопка «На ревью» неактивна, пока есть блокирующие проверки. Рядом выводится причина текстом.
- Панель группирует проверки: «Блокирует», «Предупреждения», «Информация».
- Ложное срабатывание помечается кнопкой с комментарием. Пометка пишется в аудит.
- История версий и сравнение открываются в боковой панели; сравнение идёт по абзацам.

## 7. Состояния

| Состояние       | Что показываем                                                                            |
| --------------- | ----------------------------------------------------------------------------------------- |
| Пусто           | Короткое пояснение и одно действие, например «Создать первый материал»                    |
| Загрузка        | Скелетоны карточек и строк таблиц                                                         |
| Генерация       | Стадии (сбор промпта, генерация, разбор, проверки), время, кнопка «Отменить»              |
| `needs_input`   | Список вопросов автору; у каждого вопроса кнопка «Добавить факт»                          |
| Ошибка LLM      | Понятный текст без технических деталей, код ошибки, «Повторить»; текст версии не меняется |
| Блокировка      | Причина текстом рядом с действием, а не только неактивная кнопка                          |
| Конфликт версий | Диалог «Материал изменили»: «Сравнить» и «Перезагрузить»                                  |

## 8. Компоненты

- **Кнопки:** основная, тональная (`secondary-container`), контурная, текстовая, деструктивная (`error`).
- **Чипы:** стиль, формат, статус, роль.
- **Статус:** значок и текст вместе.
- **Прочие:** карточка, таблица, поле ввода со счётчиком, переключатель темы, диалог, всплывающее уведомление, палитра команд (Ctrl+K), вкладки, подсказка.

Компоненты живут в `apps/web/src/shared/ui/` и покрываются тестами доступности. Storybook — по желанию, после E5.

---

## 9. Доступность

- Цель — WCAG 2.2 AA. Контраст текста не ниже 4,5:1 в обеих темах.
- Фокус: видимое кольцо 2 px цвета `--md-sys-color-primary`.
- Статус никогда не передаётся только цветом: всегда значок и текст.
- Все действия доступны с клавиатуры. Порядок табуляции совпадает с визуальным.
- `aria-live="polite"` для стадий генерации и результатов проверок.
- `prefers-reduced-motion` отключает анимации доски и скелетонов.
- Горячие клавиши: Ctrl+K — палитра команд, Ctrl+S — сохранить версию, Ctrl+Enter — генерация. Список доступен по `?`.

---

## 10. Тема и локаль

- По умолчанию используется системная тема (`prefers-color-scheme`). Переключатель в шапке сохраняет выбор.
- Даты форматируются через `Intl.DateTimeFormat('ru-RU')`. Разряды чисел разделяются пробелом.
- Склонения («знак», «знака», «знаков») — через `Intl.PluralRules('ru')`.
- Тексты интерфейса хранятся в одном файле `ru.ts`. Английский в v1 не поддерживается.

## 11. Прототип

[`prototype/index.html`](../prototype/index.html) показывает доску, редактор с панелью проверок, факт-базу, стили и публикации. Работает без сборки. Данные вымышлены, цифры — заглушки и не являются фактами.
