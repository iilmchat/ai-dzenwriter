# Прототип DzenWriter

Кликабельный HTML-прототип интерфейса. Открывается в браузере без сборки: `prototype/index.html`.

## Что показано

- **План:** доска статусов с карточками материалов.
- **Материал:** редактор с предпросмотром, панелью проверок и метаданными. Кнопка «На ревью» заблокирована, пока есть блокирующая проверка.
- **Факт-база:** факты разных типов, статусы, согласие на личный опыт.
- **Стили:** карточки четырёх стилей со ссылками на конфиги.
- **Публикации:** статусы и плановые даты.

## Ограничения прототипа

- Данные вымышлены. Цифры и названия — заглушки, не факты.
- Кнопки «Добавить», «Сгенерировать», «Скачать пакет» и «Указать ссылку» ничего не делают.
- Шрифты загружаются из Google Fonts. Без интернета будут системные шрифты.
- Палитра и роли берутся из `design/brand/theme-m3.css`. Расширенные цвета `--dz-*` описаны в [docs/05-ui-brand.md](../docs/05-ui-brand.md) и требуют согласования.

Тема переключается кнопкой «Тема» в шапке. По умолчанию применяется системная настройка.
